# 📚 Book & Bill

A booking and invoicing platform for small businesses.

## 🎯 Problem
Small businesses struggle with managing bookings and invoices manually.

## 💡 Solution
Book & Bill automates the entire process:
- Customers book online 24/7
- Invoices auto-generate
- Dashboard shows everything

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Auth:** JWT

## 🚀 Live Demo
[https://cosmic-kitsune-c061f9.netlify.app](https://cosmic-kitsune-c061f9.netlify.app)

## 📋 Features
- ✅ Business registration/login
- ✅ Service management
- ✅ Public booking page
- ✅ Auto invoice generation
- ✅ Dashboard with stats
- ✅ Invoice management
- ✅ Mobile responsive

## 🚀 Getting Started

### Backend

cd backend
npm install
npm run dev
Frontend
bash
cd frontend
npm install
npm start
